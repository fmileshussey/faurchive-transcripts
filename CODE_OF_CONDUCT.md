# Code of Conduct

- **Be careful with his words.** Don't put into a transcript what you think he
  should have said, and don't use the corpus to misrepresent him.

## Enforcement

The maintainer enforces this code and may edit or remove contributions, and
block contributors, who don't follow it. To report a problem privately, contact
the maintainer through the address on their GitHub profile. Reports are kept
confidential.
