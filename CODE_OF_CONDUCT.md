# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short:

- **Be respectful** — of other contributors, and of the teacher whose words this
  is. Disagree about a reading, a spelling or a source on the evidence; never
  about the person.
- **Be careful with his words.** Don't put into a transcript what you think he
  should have said, and don't use the corpus to misrepresent him.
- **No harassment**, personal attacks, or publishing anyone's private
  information.
- **Assume good faith.** Most mistakes in a transcript are mishearings, not
  carelessness.

## Enforcement

The maintainer enforces this code and may edit or remove contributions, and
block contributors, who don't follow it. To report a problem privately, contact
the maintainer through the address on their GitHub profile. Reports are kept
confidential.
